Use normal cross-native abuild with cached dependencies and two clean HOME/tmp
workspaces. KBUILD user/host/timestamp/version are fixed by _kernel_make.
Set FX0_KERNEL_MODULE_SIGNING_KEY to the existing trusted, readable absolute
signer path. The recipe rejects omitted, relative or missing paths and never
falls back to automatic key generation. No private signing key is shipped.
Normal APK and module signing use existing signers in place; do not copy,
hash or publish their bodies. Do not weaken signature verification or add trust
keys to install this package. The paired fx0-dmp-reader uses timestamp byte 16
and checks the running kernel release before capture.
The ordinary madai board remains selected. CPR/full-suspend drivers and the
optional charger policy are not promoted. Compilation is not physical proof.
Two signed clean builds, CMS/APK payload/ABI/dependencies, install hooks and
recovery must be qualified before the separately authorized device update.
The earlier 468-module unsigned build used a public verification fixture;
its binary hashes and certificate are not the normal signed-package reference.
